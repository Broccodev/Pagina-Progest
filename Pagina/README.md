## Descrição do Projeto

Landing page profissional desenvolvida para divulgação do **Sistema ProGest**, uma solução completa de gestão empresarial. A página foi criada como parte da atividade de **Projeto e Desenvolvimento com GitHub** e implementa boas práticas de versionamento e hospedagem no GitHub Pages.

A página possui as seguintes seções principais:
1. **Cabeçalho** - Navegação e CTA
2. **Hero Section** - Apresentação principal com estatísticas
3. **Funcionalidades** - Módulos e recursos do sistema
4. **Benefícios** - Vantagens de usar o ProGest
5. **Planos** - Opções de assinatura
6. **Demonstração** - Formulário para agendar demo
7. **Depoimentos** - Avaliações de clientes
8. **Contato** - Informações e formulário de teste grátis
9. **Rodapé** - Links e informações adicionais

## Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização avançada com Flexbox e Grid
- **JavaScript** - Interatividade e validação de formulários
- **Font Awesome** - Ícones
- **Google Fonts** - Tipografia (Poppins e Roboto)
- **SweetAlert2** - Notificações modernas
- **Git** - Controle de versão
- **GitHub Pages** - Hospedagem

## Funcionalidades Implementadas

- Design moderno e responsivo
- Navegação suave entre seções
- Menu mobile responsivo
- Formulários funcionais com validação
- Animações e transições CSS
- Contador animado nas estatísticas
- Cards interativos
- Layout adaptável para todos os dispositivos
- SEO básico otimizado
